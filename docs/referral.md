# 推广系统

本文档说明面板的推广体系：推广码与推广链接、免卡密体验注册、注册页选填推广码、邀请奖励与被推广人奖励、代理门槛，以及相关的数据文件与接口清单。

## 概述

普通用户在「设置 → 推广」（移动端底部导航同样有入口）获得专属推广码：

- 分享专属链接（`/#/register?ref=<推广码>`），好友打开直接进入推广注册页，免卡密注册并获得 **1 小时体验时长**。
- 每个网络（IP）仅可通过推广链接注册一个账号，防止批量薅体验。
- 正常卡密注册页也可**选填**推广码：填写即绑定邀请关系；若使用 30 天及以上时间卡注册，立即按有效购买结算奖励。
- 被推广人使用 30 天及以上时间卡**注册或续费**时，双方都获得奖励：

| 对象 | 奖励 | 触发条件 |
| --- | --- | --- |
| 邀请人 | 账号有效期 +5 天 | 被推广人使用 ≥30 天（含永久）时间卡注册或续费 |
| 被推广人 | 账号有效期 +2 天（在卡密时长之外） | 同上；永久卡不叠加（本身无期限） |

- 有效推广累计 **10 人**（被推广人产生过有效购买）后自动升级为**代理**，代理可享 7 折拿卡优惠（线下联系管理员兑换，面板不做卡密折扣）。

## 数据模型

邀请关系与奖励状态保存在用户记录（`core/data/users.json`）中：

| 字段 | 说明 |
| --- | --- |
| `referredBy` | 邀请人的用户名，注册时绑定 |
| `referralCode` | 本人专属推广码，首次查看推广页时生成，8 位大写字母数字 |
| `validPurchaseAt` | 首次有效购买时间；是否计为有效推广的依据 |
| `isAgent` | 是否已达代理门槛 |

IP 限制记录保存在 `core/data/referral-ips.json`：

```json
{
  "1.2.3.4": { "username": "trial01", "at": 1792400000000 }
}
```

推广规则常量位于 `core/src/models/user-store.ts`：

| 常量 | 值 | 说明 |
| --- | --- | --- |
| `REFERRAL_TRIAL_MS` | 1 小时 | 推广链接注册的体验时长 |
| `REFERRAL_QUALIFY_CARD_MS` | 30 天 | 有效购买的时间卡门槛 |
| `REFERRAL_REWARD_MS` | 5 天 | 邀请人每次有效购买的奖励 |
| `REFERRAL_REFEREE_BONUS_MS` | 2 天 | 被推广人注册/续费时的额外奖励 |
| `REFERRAL_AGENT_TARGET` | 10 | 自动升级代理的有效推广人数 |
| `REFERRAL_CODE_LENGTH` | 8 | 推广码长度（字符集去除易混字符） |

## 奖励结算

- **注册结算**（`registerUser`）：卡密注册时填写了有效推广码且卡时长 ≥30 天，新用户 `validPurchaseAt` 记为当前时间、有效期额外 +2 天，邀请人有效期 +5 天（邀请人到期时间从「当前剩余或当前时间」中较大者起算，可叠加）。
- **续费结算**（`renewUser`）：被推广人核销 ≥30 天时间卡续费时，本人 +2 天、邀请人 +5 天，并刷新 `validPurchaseAt`。
- 邀请人若为永久有效期（无到期时间），不加天数，仅计有效购买与代理进度。
- 每次结算后重算邀请人的有效推广数，达到 10 人自动置 `isAgent=true`。
- 结算与核销在同一次保存中完成，无中间状态；卡密核销仍不可撤销。

## 面板展示

- 推广页：专属推广码与链接、复制按钮、绑定被推广人列表（是否有效购买）、有效推广数与代理进度、规则说明。
- 注册页（卡密注册）：推广码选填，提示「填写推广码并使用 30 天及以上卡密注册，你会额外获得 2 天时长，邀请人获得 5 天时长」。
- 推广注册页：推广码只读展示，邀请人用户名与代理标识实时校验（`GET /api/register/referral-info`），链接无效时回退为普通卡密注册。

## 接口清单

公开接口（无需登录）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| POST | `/api/register/referral` | 推广链接体验注册（`username` / `password` / `refCode`），按 IP 限一号 |
| GET | `/api/register/referral-info?code=` | 查询推广码归属（用户名、是否代理），注册页展示用 |

普通用户接口（需登录）：

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| GET | `/api/user/referral` | 推广概览：推广码、绑定的被推广人列表、有效推广数、代理状态、门槛与奖励天数 |

卡密注册接口 `POST /api/register` 增加可选 `refCode` 字段，见[卡密系统与多用户](card-key.md)。
