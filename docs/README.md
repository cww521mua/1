## 维护约定

- 根目录只保留作为仓库入口的 `README.md`。
- 安装、部署、功能和用户配置写入根 README。
- 实现原理、协议研究和工具使用等专题内容写入 `docs/`。
- 文档引用仓库文件时使用相对仓库根目录的路径，示例命令默认从仓库根目录执行。
- 新增专题文档后同步更新本索引和根 README 的“项目文档”章节。
